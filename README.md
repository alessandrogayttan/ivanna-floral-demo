# Boutique Floral Ivanna · Demo

Propuesta web independiente para presentar a Boutique Floral Ivanna en Zapopan, creada por Soluciones con Código. No es su sitio oficial.

## Funciones

- Diseño adaptable en tonos rosa, ilustraciones florales, lazos y corazones.
- Animaciones de entrada, pétalos suaves y pequeños efectos al interactuar. Respeta la preferencia de reducir movimiento.
- Colección de cuatro inspiraciones con filtros, detalles y favoritos locales.
- Personalizador de dedicatoria con tarjeta que gira, frases sugeridas, tonos, ocasión, fecha y presupuesto.
- Consulta preparada por WhatsApp. El visitante revisa y envía su propio mensaje; no confirma pedidos ni procesa pagos.
- Dirección con enlace a Google Maps, teléfono, preguntas frecuentes e información de privacidad.

## Tecnología y privacidad

HTML, CSS y JavaScript sin dependencias de terceros. GitHub Pages puede servir directamente esta carpeta. No hay backend, analítica, anuncios ni formularios que almacenen datos personales. Solo se guardan identificadores de favoritos en localStorage. Las consultas se preparan en el navegador y se comparten con WhatsApp al abrirlo. Google Maps y WhatsApp tienen sus propias políticas.

La propuesta incluye noindex y robots.txt para desalentar su indexación. Para convertirla en sitio oficial, el negocio debe validar contenidos, fotografías, catálogo, horarios y condiciones de pedido.
